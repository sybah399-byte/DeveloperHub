\# DeveloperHub UI Guidelines



Version: 1.0



\---



\# Design Philosophy



DeveloperHub should feel like a professional desktop IDE rather than a typical website.



The interface should be clean, fast, information-dense, and consistent.



Primary inspiration:



\- VS Code

\- GitHub Desktop

\- JetBrains IDEs

\- Windows Terminal

\- Docker Desktop



\---



\# Theme



Dark mode is the default.



Light mode may be added later.
